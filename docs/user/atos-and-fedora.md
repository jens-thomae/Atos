# Atos and Fedora

Atos is built from Fedora Linux packages, but it is not Fedora. It is not provided or supported by the Fedora Project. Official Fedora Linux is available from the Fedora Project at <https://fedoraproject.org/>.

## What your computer calls itself

- The system name is **Atos 45**. You see it at the start-up messages, on a text login screen and in the boot menu (hold a key while the computer starts to open it).
- The computer's network name is **atos**, unless you have given it a name of your own.
- Programs that ask which system they run on get Atos as the answer, and "like Fedora" as the family. That keeps programs that support Fedora working.

If you installed Atos before this change, the next update renames it. The boot menu then shows the new entry as **Atos 45** and the previous version under its old name, **Fedora Linux 45 (Forty Five)**, until the update after that. A computer still called **fedora** on the network is renamed **atos**; a name you chose stays.

## Reporting a problem

Report problems with Atos at <https://github.com/jens-thomae/Atos/issues>, not to Fedora: the Fedora Project cannot help with Atos.

Some places still say Fedora, because they name where a part comes from, not your system: package names, the software sources Atos is built from, licence files and the kernel version (`.fc45`).
