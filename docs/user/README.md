# User documentation

Pages here are for people who use Atos, not for people who build it. A card that adds or changes user-visible behaviour adds or updates a page here (spec §9, definition of done).

- **Who reads it:** a user at their own computer, with no knowledge of the code or of our terms for it.
- **Voice:** plain and direct. Say what the user sees and what to do, in short steps. Use the glossary words (spec §11) the user sees on screen; leave out component IDs, card numbers and decision IDs.
- **Be honest about risk:** say what a step changes, what it cannot undo and how to go back.
- **One task per page**, named for the task ("Turning Secure Boot off and on").
- **Developer detail** (how it works, why it was decided) stays under `docs/components/` or `docs/decisions/`; link to it from the page if useful.
